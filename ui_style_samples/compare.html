ESP32 NAT Router · Web UI STYLE REVIEW · 03 NOV 2026

四种方向，同一种克制

同一套页面内容——状态、导航、表单、客户端列表、危险操作——四种设计语言。
每组都只用系统字体、内联 CSS 和内联 SVG，没有外部依赖，可以直接嵌入固件页面。
区别在于气质：仪表的精确、纸本的从容、原生的顺手、终端的直接。

01

Instrument

工程仪表

精确、克制、有设备感。暖灰纸底，1px 分隔线，深绿只用于“通”。数字走等宽，标题用 10px 大写字母。没有任何渐变、阴影或装饰性图形。

适合日常管理；桌面和手机上都像一台调好的设备。

02

Editorial

纸本手册

像一本排过版的手册。暖白纸色，衬线正文，标题与正文靠字号拉开层级。状态用点线引导（·······），章节用编号索引，只有一种锈红作强调色。

适合想让界面留下记忆点；信息型页面，阅读舒服。

03

Native

系统原生

不用学习，拿起来就会。iOS 式分组列表、系统蓝、44px 行高、真实开关、内缩分隔线。图标是内联 SVG，不是 emoji；颜色只用来区分入口和状态。

适合手机端为主；第一次配置路由器的人。

04

Console

维护终端

设备直接说话。近黑面板、单一琥珀色、等宽字体、方角、1px 框线。分区写成 01 / connection，状态是 link up，没有霓虹和发光。

适合喜欢深色或终端习惯的用户；刷机、抓包场景。

选定方向后，先落到 / 与 /config 两个页面验证，再迁移其余页面。样式全部内联，不引入框架与外部字体。
